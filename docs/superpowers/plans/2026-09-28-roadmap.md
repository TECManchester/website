# WordPress redesign — plan roadmap

Spec: `docs/superpowers/specs/2026-09-28-wordpress-redesign-design.md`

The spec covers several independent subsystems, so it is delivered as six plans. Each plan ends with
a working, testable site. Each is written after the previous one lands, so it can cite real file
names and interfaces instead of guesses.

| # | Plan | Spec sections | Delivers | Status |
|---|---|---|---|---|
| 1 | **Foundation** | §3, §5.1–5.3, §6.1, §7 (Site Manager role), §8 (pinning), §9 | Pinned Docker env (MariaDB 10.6, `wp6d_`, Mailpit, node/composer tools), `elevation` theme with design tokens, header and footer, `elevation-core` with Church Settings, bindings and tokens, the block build pipeline, a seed CLI with a hash guard and cut-off | done: `2026-09-28-plan-1-foundation.md` |
| 2 | **Patterns and pages** | §5.4, §5.5, §6.8 (consent, GA4, embed gate), §6.6 blocks `hero-slideshow`, `leadership-grid`, `icon`, §6.9 (Redirection seeding), §11 | All section patterns; the 11 redesign pages and 4 kept campaign pages seeded; consent banner and GA4; redirects; privacy notice; hero-slides settings group; editor toolbar button that inserts settings tokens; `bin/export-page.sh` | not written |
| 3 | **Events** | §6.2 | `event` post type, `Event_Time`, event blocks and calendar, archive and single templates, fixtures | not written |
| 4 | **YouTube and sermons** | §6.3, §6.4 | YouTube client, live REST endpoint and swap, sermons/series/speakers, hourly draft import, Watch page | not written |
| 5 | **Forms, groups, visits, announcements** | §6.5, §6.6, §6.7, §6.10 (forms), §7 | 9 Fluent Forms with validation, rate limit and notifications; connect-group directory; Plan a Visit and connect card; announcements via REST; Fluent Forms per-form access for Site Managers | not written |
| 6 | **Live data, parity and go-live prep** | §6.10 (migration), §10, §12 | `bin/migrate-live-data.php` (entries, redirects, users), local Supabase parity comparison, the full §12 test sweep, `docs/go-live.md`, `docs/editing-guide.md`, seed cut-off | not written |

Order matters: 2 needs 1's tokens, styles and seed CLI. 3–5 each need 2's patterns. 6 needs all
content types to exist.
